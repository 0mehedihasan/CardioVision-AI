# ============================================================
# CardioVision AI — dependencies
#
# There is deliberately no dependency list in this file.
#
# The dependencies live in pyproject.toml, and this file installs the
# project itself so that pip reads them from there. Keeping a second
# hand-maintained copy here is how a list drifts: the previous version of
# this file was missing scipy, which the ECG preprocessing needs, so
# `pip install -r requirements.txt` produced an install that imported
# fine and then failed at the first ECG upload.
#
# Install (editable, so `src/` edits take effect without reinstalling):
#
#     python3 -m venv .venv
#     source .venv/bin/activate
#     pip install -r requirements.txt
#
# Equivalent, and what the README recommends:
#
#     pip install -e .              # runtime only
#     pip install -e ".[dev]"       # + pytest, httpx, ruff
#     pip install -e ".[notebooks]" # + pandas, matplotlib, sklearn, wfdb
#
# On Apple Silicon, torch comes from the default index as the MPS-enabled
# build automatically — do not add an --index-url here.
#
# For a byte-reproducible environment, generate a lock file from a working
# install (`pip freeze > requirements.lock`) rather than pinning below.
# ============================================================

-e .
